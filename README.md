# Cyber Cyclone

Jogo web integrado ao conector universal do Projeto Daniel.

## Arquitetura

- `src/core/`: runtime e ciclo de vida
- `src/game/`: regras e comandos do jogo
- `src/integrations/`: Projeto Daniel e eventos externos
- `src/ui/`: viewport e interface
- `src/main.js`: composição dos módulos
- `tests/`: QA automatizado
